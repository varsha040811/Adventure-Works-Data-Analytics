# Adventure-Works-Data-Analytics
Project Overview

This project focuses on analysing Adventure Works business data to understand sales performance, customer behaviour, product performance, regional trends and profitability.

The project was completed using four data analytics tools: Microsoft Excel, SQL, Power BI and Tableau.

Business Objectives

Analyse overall sales and profit performance.

Identify top-performing products and customers.

Understand regional and category-wise sales.

Evaluate production costs and profitability.

Identify business trends and patterns.

Tools & Technologies

Microsoft Excel

SQL

Power BI

Power Query

DAX

Tableau

Project Modules

1. Excel

Data organisation, cleaning, calculations, PivotTables and analysis.

2. SQL

Data querying, filtering, aggregations, joins and business analysis.

3. Power BI

Data transformation, data modelling, DAX calculations, KPIs and interactive dashboards.

4. Tableau

Data visualisation and analysis of business performance through interactive dashboards.

Sales Performance

Product Analysis

Customer Analysis

Conclusion

This project helped develop practical skills in data cleaning, data analysis, querying, data visualisation and dashboard development using multiple analytics tools.
